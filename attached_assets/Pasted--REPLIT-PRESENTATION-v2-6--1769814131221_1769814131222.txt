# ✅ ТЗ ДЛЯ REPLIT: PRESENTATION v2 (6 слайдов) — готово к внедрению

## Общие правила (важно)

1. **Не использовать внутренние слова в UI**:

   * “Killer Feature” (как заголовок) — **нельзя**
   * “Killer-feature” — **нельзя**
   * “Форматы / Механика / Воронка / Трафик / Лиды” — **нельзя**
2. Слайды читаются за 5–7 секунд: **минимум текста**, максимум воздуха.
3. В каждом слайде: **Badge (маленький) + H1 + Sub + 1 визуальный блок**.
4. На последнем слайде — 2 CTA:

   * Primary: “Показать в действии (3 минуты)” → `/chat-demo`
   * Secondary: “Поговорить вживую” → `/live`

   - текст “Оставишь контакт — пришлю пример под твою нишу.” → `/contact`

# UI/UX требования (чтобы “классно реализовал”)

* Карточки: radius 18–20, border 1px light, мягкая тень
* Badge: маленький, пастельный, без красного
* Воздух: большие отступы сверху/снизу
* Никаких длинных списков (макс 4 пункта)
* Текст: 1–2 строки в блоке
* Навигация: одна кнопка “Далее” внизу (sticky)
